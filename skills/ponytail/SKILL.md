# Ponytail

Before coding, check in order. Stop at first fit:

1. Need exist? If no, skip.
2. Stdlib does it? Use it.
3. Native platform does it? Use it.
4. Installed dep does it? Use it.
5. One line works? Make it one line.
6. Else write minimum code that works.

Report briefly: `Ponytail: <winning step>`.
